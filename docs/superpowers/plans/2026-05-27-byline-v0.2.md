# Byline v0.2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Apply the v0.2 addendum on top of v0.1: commit history forensics, doc/code alignment, within-repo self-baseline, voice + disclosure detection, boilerplate density, and three new LLM-touching subcommands (`questions`, `chat`, `align`).

**Architecture:** Deterministic backbone with optional Claude calls. `anthropic` must never be imported at module top level — defer to inside functions. All v0.1 framing rules still apply.

**Source of truth:** v0.2 addendum in the user message. Refer to it for exact behavior, signatures, prompts, and acceptance criteria.

**Framing rule:** unchanged from v0.1. "Comparative attribution," "signals," "divergence." Never "AI detector" / "detect AI" / authorship claims. LLM outputs get post-processed to strip those phrases.

---

## Execution order (matches §12 of the addendum)

- **Task 1: Version bump + CHANGELOG skeleton + deps** — `__version__ = "0.2.0"`, add `gitpython>=3.1` and `prompt_toolkit>=3.0` to runtime deps; keep `anthropic>=0.40` under `[llm]` extra. Verify both install paths work.
- **Task 2: `byline/repo_fetcher.py`** — `cloned_repo` context manager, `is_local_path`, `detect_default_branch`. Tests with a small local-bare-repo fixture.
- **Task 3: Extend `byline/models.py`** — add the 9 new models from §4 (CommitTimelineFinding, CommitMessageStyleFinding, AuthorIdentityFinding, FileEvolutionFinding, HistoryFindings, AlignmentCheck, AlignmentFindings, VoiceFinding, BoilerplateFinding, SelfBaselineFinding, Question, QuestionSet). Extend `AuditResult` with optional fields.
- **Task 4: `byline/voice.py`** + tests + `disclosed_ai_repo` fixture. First-person + AI disclosure detection.
- **Task 5: `byline/boilerplate.py`** + tests. Meta-file presence density.
- **Task 6: `byline/self_baseline.py`** + tests. Three-way within-repo style comparison.
- **Task 7: `byline/history.py`** + `tests/test_history.py` + 4 synthetic git fixtures (pasted, iterated, bursty, drifted). Conftest builder.
- **Task 8: `byline/alignment.py`** (deterministic mode first) + `tests/test_alignment_deterministic.py` + 2 synthetic doc fixtures (aligned/misaligned).
- **Task 9: Extend `byline/llm.py`** — add the four new system prompts as verbatim constants; add prompt functions (alignment-semantic, alignment-summary, questions, chat). Wrap all anthropic imports inside functions. Post-process outputs to strip banned phrases.
- **Task 10: Semantic alignment LLM hook** + `tests/test_alignment_semantic.py` (mocked client).
- **Task 11: `byline/questions.py`** + `tests/test_questions.py` (mocked).
- **Task 12: `byline/chat.py`** + `tests/test_chat.py` (command parsing only).
- **Task 13: Extend `byline/cli.py`** — add `questions`, `chat`, `align` subcommands; extend `audit` with `--no-history`. Update tests.
- **Task 14: Extend `byline/compare.py`** `overall_signal()` per §8 (history, alignment, voice, boilerplate, self_baseline contributions; disclosure as positive signal). Wire new findings into `audit()` orchestrator.
- **Task 15: Extend `byline/report.py` + `byline/report_docx.py`** — render the 6 new sections in the order from §8.
- **Task 16: CI `test-base-install` job** — `.github/workflows/ci.yml` gets a second matrix that installs without `[llm]` and runs deterministic tests only.
- **Task 17: Update README + `docs/methodology.md` + CHANGELOG v0.2.0 entry**.
- **Task 18: Full acceptance pass** — both v0.1 and v0.2 §10 criteria.

**Smoke test (after Task 18):** `byline audit https://github.com/rupivbluegreen/byline --candidate rupivbluegreen` (no LLM) then with `--with-llm`. Coherent reports both ways.

# Byline v0.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the full v0.1 of `byline`, a comparative attribution analysis tool for take-home hiring submissions on GitHub, as a pip-installable Python CLI with tests, docs, and CI.

**Architecture:** Typer-based CLI with three commands (`audit`, `baseline`, `scan`). Pydantic models throughout. Direct httpx calls to GitHub REST API (no PyGithub). Pure functions for metrics/fingerprints. Markdown + DOCX report rendering. Optional Anthropic LLM qualitative pass.

**Tech Stack:** Python 3.10+, Typer, httpx, pydantic v2, python-docx, textstat, language_tool_python, rich, anthropic (optional). Black + Ruff + mypy. pytest.

**Source of truth:** The CLAUDE.md spec in the user message defines exact module layout (§3), data models (§5), function signatures (§6-10), CLI surface (§4), and acceptance criteria (§15). This plan organizes execution; refer to the spec for any detail.

**Framing rule (non-negotiable, see §0):** "comparative attribution analysis," "divergence," "signals." Never "AI detector" / "detect AI" / authorship claims. This applies to code, docs, CLI strings, and report text.

## Notes on ambiguities (documented per §17.8)

- `byline scan` accepts either a GitHub URL or a local path; local path is preferred for v0.1 speed. URL path uses the GitHub API to fetch the tree and key files. Documented in `cli.py` docstring.
- `common_5000.txt` is bundled. If the network is unavailable at build time, falls back to a smaller (~500-word) embedded list and logs a warning. Documented in CHANGELOG.
- LanguageTool is lazy-initialized; `typo_rate` returns `0.0` and logs a warning if the LanguageTool server cannot start.
- `compute_baseline_profile` concatenates all `WritingSample.text` then runs `metrics_for_text(..., kind="prose")`. Documented in docstring.
- `audit` accepts target as either URL or local path (mirrors `scan`).

# Contributors

`byline` is built and maintained by:

- **rupivbluegreen** ([github.com/rupivbluegreen](https://github.com/rupivbluegreen)) — project owner, direction, spec author
- **Claude Code** (Anthropic) — implementation under direction, via the Claude Code CLI

The codebase follows a subagent-driven development workflow: rupivbluegreen authors the specs and drives the high-level decisions; Claude Code carries out the implementation tasks against those specs and is reviewed at each task boundary. Both contributors are credited on every commit via `Co-Authored-By` trailers.

Source repository: https://github.com/rupivbluegreen/byline
Distribution on PyPI: https://pypi.org/project/byline-audit/

Want to contribute? See the open issues tagged `good-first-issue` and `help-wanted` at https://github.com/rupivbluegreen/byline/issues.
